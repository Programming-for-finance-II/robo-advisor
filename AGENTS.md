## Agent Roles

### Agent 1: CI Validator (ci.yml)
- **Trigger:** Every push and PR to `main`
- **Role:** Runs `ruff check` (lint) and `pytest` (test suite)
- **Output:** Green/red status on every PR — blocks merge on failure

### Agent 2: Docstring PR Agent (agent_pr.yml)
- **Trigger:** `workflow_dispatch` or push to `backend/optimizer/`
- **Role:** Calls Claude API to generate/update docstrings in the optimizer module
- **Output:** Opens an automatic PR with diff and descriptive body
- **Status:** Planned for Week 4 (P1 owner)

### Agent 3: LLM Narrator Agent (backend/llm/narrator.py)
- **Trigger:** User submits a query on the Chat Advisor page
- **Role:** Calls Claude API to generate a natural-language explanation of the
  portfolio recommendation, strictly grounded in the Ground Truth JSON produced
  by the optimizer. The agent is a *narrator*, not a calculator — it never
  invents numbers or makes forward-looking predictions.
- **Constraints:**
  - Input: Ground Truth JSON (weights, risk metrics, profile_label, regime,
    regulatory_context)
  - Forbidden: any numerical claim not present in the Ground Truth JSON
  - Required: EU Awareness Rule 9 — explicit disclosure that SCF data is
    US-sourced and may not reflect EU investor behaviour
  - Required: MiFID II educational disclaimer auto-appended to every response
- **Output:** Validated natural-language narrative passed to the Validator Agent
- **Status:** Planned for Week 3 (P4 owner)

### Agent 4: LLM Validator Agent (backend/llm/validator.py)
- **Trigger:** Every response generated by the Narrator Agent before display
- **Role:** 4-step post-generation filter that enforces output safety:
  1. **Forbidden phrases check** — blocks investment advice language
     (e.g. "you should buy", "guaranteed return")
  2. **Allowed numbers check** — flags any number not present in Ground Truth JSON
  3. **Disclaimer presence check** — ensures MiFID II disclaimer is appended
  4. **Prompt injection defense** — detects and neutralises injection attempts
     in user input
- **Fallback:** If any check fails, returns a safe static message instead of
  the LLM response
- **Output:** Sanitised, compliant text shown to the user in the UI
- **Status:** Planned for Week 3 (P4 owner)

## Agentic Workflow Philosophy

AI agents contribute to:
1. **Code quality enforcement** (CI agent — automated lint + test)
2. **Documentation generation** (Docstring PR agent — Claude API via GitHub Actions)
3. **Runtime narrative generation** (LLM Narrator — Claude API called per user query)
4. **Runtime output safety** (LLM Validator — 4-step filter on every LLM response)
5. **Development assistance** (Claude used interactively by all team members)

All AI tool usage is acknowledged in the academic PDF (Section 7: Lessons Learned).
